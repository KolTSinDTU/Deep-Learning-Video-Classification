\section{Introduction}
\label{sec:intro}
Video classification assigns an action label to a sequence of frames.
Individual frames provide appearance and pose cues, while changes across
frames can reveal motion. This project studies how the way a network combines
frames affects recognition on a ten-class workout subset of
UCF101~\cite{soomro2012ucf101}.

This project aims to compare a few single-stream models with a dual-stream optical-flow model. 
The project also examines subject leakage through a comparison using corrected 
splits and an RGB/optical-flow dual-stream model.
